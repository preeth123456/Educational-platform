# Eduyata - AI-Powered Education Platform

## Overview

Eduyata is a modern education platform that leverages artificial intelligence and augmented reality to create immersive learning experiences. The application is built as a full-stack web application with a React frontend and Express backend, featuring a responsive landing page that showcases the platform's core features: AI Buddy Assistant, AR Learning, Gamified Assessments, Analytics Dashboard, and Personalized Learning Paths.

## System Architecture

### Frontend Architecture
- **Framework**: React 18 with TypeScript
- **Styling**: Custom CSS with CSS variables for theming, no framework dependencies
- **UI Components**: Radix UI primitives with shadcn/ui component library
- **State Management**: React Query (@tanstack/react-query) for server state
- **Routing**: Wouter for client-side routing
- **Build Tool**: Vite for fast development and optimized builds

### Backend Architecture
- **Runtime**: Node.js with Express.js framework
- **Language**: TypeScript with ES modules
- **Database**: PostgreSQL with Drizzle ORM
- **Database Provider**: Neon Database (serverless PostgreSQL)
- **Session Management**: Connect-pg-simple for PostgreSQL session store
- **Development**: tsx for TypeScript execution in development

### Design System
- **Component Library**: Custom implementation using Radix UI primitives
- **Theming**: CSS custom properties with light/dark mode support
- **Typography**: Inter font family from Google Fonts
- **Icons**: Font Awesome 6.0 for iconography
- **Responsive Design**: Mobile-first approach with CSS Grid and Flexbox

## Key Components

### Landing Page Components
1. **Header**: Navigation with logo, menu items, and authentication buttons
2. **Hero Section**: Primary value proposition with call-to-action buttons
3. **Features Section**: Six-feature grid showcasing platform capabilities
4. **Popular Modules**: Course cards with ratings, pricing, and instructor information
5. **Testimonials**: Student reviews with photos and ratings
6. **CTA Section**: Newsletter signup and final call-to-action
7. **Footer**: Company information, links, and contact details

### UI Component System
- Comprehensive set of reusable components based on Radix UI
- Form components with React Hook Form integration
- Data visualization components with Recharts
- Interactive elements (dialogs, dropdowns, tooltips)
- Layout components (cards, separators, scrollable areas)

### Authentication & User Management
- User schema with username/password authentication
- Session-based authentication with PostgreSQL storage
- In-memory storage implementation for development
- Extensible storage interface for production database integration

## Data Flow

### Frontend Data Flow
1. **Component Rendering**: React components render UI based on state
2. **User Interactions**: Events trigger state updates or API calls
3. **Server Communication**: React Query manages API requests and caching
4. **State Updates**: Component re-renders based on new data

### Backend Data Flow
1. **Request Processing**: Express middleware handles incoming requests
2. **Database Operations**: Drizzle ORM provides type-safe database access
3. **Response Generation**: JSON responses sent back to frontend
4. **Session Management**: PostgreSQL-backed session storage

### Development Data Flow
- **Hot Module Replacement**: Vite provides instant updates during development
- **TypeScript Compilation**: Real-time type checking and compilation
- **Database Migrations**: Drizzle Kit handles schema changes

## Deployment Strategy

### Development Environment
- **Local Development**: Vite dev server with HMR
- **Database**: Neon Database serverless PostgreSQL
- **Environment Variables**: DATABASE_URL for database connection
- **Build Process**: Vite builds client, esbuild bundles server

### Production Build
- **Client Build**: Static assets generated by Vite
- **Server Build**: ESM bundle created by esbuild
- **Database**: Production PostgreSQL via Neon Database
- **Process Management**: Node.js process for server execution

### Architecture Decisions
1. **Database Choice**: PostgreSQL chosen for reliability and ACID compliance
2. **ORM Selection**: Drizzle ORM provides type safety and performance
3. **Frontend Framework**: React selected for component reusability and ecosystem
4. **Styling Approach**: Custom CSS chosen over frameworks for design flexibility
5. **State Management**: React Query chosen for server state caching and synchronization
