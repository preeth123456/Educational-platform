How to Run: Because of browser security (CORS), you cannot simply double-click index.html. You must run a local server using one of the commands below:

Option A: Python (Recommended)

# Run in this folder:
python -m http.server 8000

# Then open http://localhost:8000

Option B: Node.js

# Run in this folder:
npx serve

# Then open the URL shown

Integration Snippets

Python (Requests)

Prerequisite: pip install requests

import requests

API_KEY = "{{ key.key_value }}"
BASE_URL = "http://localhost:8001/api/v1"

headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

response = requests.get(f"{BASE_URL}/students/", headers=headers)
print(response.json())

Node.js (Axios)

Prerequisite: npm install axios

const axios = require('axios');

const config = {
    headers: { Authorization: 'Bearer {{ key.key_value }}' }
};

axios.get('http://localhost:8001/api/v1/students/', config)
    .then(res => console.log(res.data))
    .catch(err => console.error(err));
